## Sütun anahtarı

- **Yazar v.** — yazar profil versiyonu (v1.0 = ilk modüler kurulum, §0.5 yürütme protokolü dahil)
- **Aforizma** — `citations/canonical-sources.md`'den seçilen Japon kavramı veya aile sahne kaynağı; birebir kopya yasak, paraframe
- **Manifesto** — Demet'te yapılandırılmamış (0); kullanılmaz
- **Anekdot** — anekdot türleri:
  - **T1** = sofra / pazar / mevsim sebzesi
  - **T2** = Japonya hatırası / JETRO / Tokyo-Kyoto kavramsal sahne
  - **T3** = annenin sofrası / kuşak köprüsü
  - **T4** = kızlarla pazar / sohbet (anonim)
  - **T5** = HRT akran çerçevesi / hekimle sade cümle
  - **T6** = çay ritüeli / sabah penceresi
  - **T7** = Japon kavramı + Türkçe açıklama (ma, mottainai, wabi-sabi vb.)
- **Açılış** — `signature_phrases_acilis`'ten 10 kalıp
- **Başlık tipi** — Kültürel köprü / Tireli sade / Mevsim kültürü / Aile sıcaklığı / Japon kavramı + Türkçe açıklama
- **Mevsim** — yazıldığı mevsim
- **Notlar** — özel durum; **muayene odası bilgisi VE sosyal yakınlık bilgisi sızıntı YASAK**
