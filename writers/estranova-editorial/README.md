# Estranova Editörleri

`estranova-editorial` kişi/yazar profili değildir; Estranova'nın kurumsal editöryal imzasıdır.

## Kullanım

- Görünür imza: **Hazırlayan: Estranova Editörleri**
- Kullanım alanı: temel rehberler, hub tamamlayıcıları, açıklayıcı sağlık haritaları, sayı dosyası omurgaları
- Onay kapısı: KC editör doğrudan onayı + tıbbi konularda Bilimsel Editör incelemesi
- Yazar kadrosunda görünmez; `src/data/writers.ts` içinde kurumsal byline olarak çözülür

## Stil Dosyaları

- `hot.md` — Estranova Editorial Gloss için kanonik stil çekirdeği

## Üst İlke

Estranova Editörleri yazıları, bir kadın dergisinin görsel sezgisi ve ritmiyle açılabilir; ancak klinik satış, kişisel köşe yazısı veya akademik rapor tonuna kaymaz. Vogue / Harper's Bazaar / Marie Claire düzeyinde seçicilik ve atmosfer hedeflenir; hiçbir dış yayın, marka cümlesi veya bireysel yazar sesi taklit edilmez.
