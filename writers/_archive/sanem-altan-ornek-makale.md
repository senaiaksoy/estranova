# Sanem Altan — Emekli V1 Pilot Kaydı

> **AUDIT-ONLY / ÜRETİMDE KULLANMA**

Bu dosyada daha önce Sanem Altan imzasıyla, yazar tarafından onaylanmamış
birinci tekil sağlık ve aile sahneleri içeren bir persona v1 pilotu
bulunuyordu. Kamusal Git deposu özel taslak kasası olmadığı ve emekli etiketi
erişim kontrolü sağlamadığı için pilot gövdesi 12 Ağustos 2026 tarihinde
izlenen çalışma ağacından kaldırıldı.

Bu kayıttan üretime aktarılabilecek tek ders şudur:

- yaşayan bir yazar adına kurgusal birinci tekil sahne yalnız Git dışı özel
  seed bankasında ve iç yazar-inceleme taslağında kullanılabilir;
- taslak açıkça `KURGUSAL / YAZAR TEYİDİ BEKLİYOR` diye işaretlenir;
- Sanem'in sınıflandırması ve nihai metin hash'ine bağlı yazılı onayı olmadan
  imzalı yayına dönüşemez;
- eski metin gold-standard, few-shot veya üslup örneği değildir.

Kurgusal sahne gerekiyorsa
`npm run writer:seed -- --writer sanem-altan --seed-id <kimlik>` akışıyla
yalnız seçilmiş tek, redakte seed kullanılır. Ham özel banka veya emekli pilot
gövdesi üretim bağlamına yüklenmez.
