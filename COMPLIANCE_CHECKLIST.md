# COMPLIANCE_CHECKLIST.md

Use this checklist before approving any page, component, prompt, or copy.

---

## A. POSITIONING CHECK

- [ ] Does this page feel like an editorial health information page?
- [ ] Does it avoid looking like a clinic marketing page?
- [ ] Does it avoid looking like a physician promotion page?
- [ ] Does it avoid looking like a treatment sales funnel?
- [ ] Does it avoid looking like a product/subscription page?

If any answer is no, revise.

---

## B. CTA CHECK

### Allowed examples
- Rehberi keşfet
- Belirtileri değerlendir
- Bilgi al
- İçeriği incele
- Daha fazla bilgi

### Forbidden examples
- Randevu al
- Tedaviye başla
- Hemen başvur
- Şimdi başla
- Paketleri incele
- Fiyat al

Checklist:
- [ ] CTA is neutral
- [ ] CTA does not imply treatment purchase
- [ ] CTA does not imply clinical service enrollment
- [ ] CTA does not create urgency pressure

---

## C. LANGUAGE RISK CHECK

Make sure the page does NOT include:
- [ ] "en iyi"
- [ ] "en başarılı"
- [ ] "garantili"
- [ ] "kesin çözüm"
- [ ] "başarı oranı"
- [ ] superiority comparisons
- [ ] treatment promises
- [ ] promotional testimonials
- [ ] sales language
- [ ] campaign/discount language

---

## D. PAGE STRUCTURE CHECK

- [ ] Page is structured like a website page, not an app screen
- [ ] Navigation is website-style, not mobile-app style
- [ ] The layout supports reading and guidance
- [ ] The page contains informational sections
- [ ] The page does not rely on sales-funnel blocks

---

## E. VISUAL CHECK

- [ ] Visual style is premium editorial + medical trust
- [ ] It does not look like a beauty/cosmetic brand
- [ ] It does not look like a startup SaaS dashboard
- [ ] It does not look like a supplement/product page
- [ ] It does not use exaggerated suffering imagery
- [ ] It does not center product/device-like visuals unnecessarily

---

## F. TRUST CHECK

- [ ] Editorial or expert review structure is visible where appropriate
- [ ] Medical disclaimer is present where needed
- [ ] Footer includes policy/disclaimer/privacy structure
- [ ] The page supports trust more than conversion

---

## G. EXPERT CHECK

- [ ] Expert presence is framed as editorial review / expert contribution
- [ ] There is no overt physician self-promotion
- [ ] There are no superiority or ranking claims
- [ ] Clinical insight is informative, not promotional

---

## H. CONTENT CHECK

- [ ] Page explains rather than sells
- [ ] Information is organized and scannable
- [ ] Tone is calm and medically literate
- [ ] Tone avoids hype, fear, and miracle framing
- [ ] If article page: includes summary / quick answer

---

## I. FINAL DECISION TEST

Ask these 5 questions:

1. Would this still make sense if it were published as a health editorial article?
- [ ] Yes
- [ ] No

2. Does this page push the user toward a medical service too directly?
- [ ] Yes
- [ ] No

3. Does this page feel more like information than promotion?
- [ ] Yes
- [ ] No

4. Is the tone neutral enough to preserve trust?
- [ ] Yes
- [ ] No

5. If reviewed critically, would this page look safer as a publication than as an advertisement?
- [ ] Yes
- [ ] No

If any answer is unfavorable, revise before publishing.
