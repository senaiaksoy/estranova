# Tiroid mi Menopoz mu? — Onay Bekleyen Paket

- **Yazar:** Dr. Metin Alış
- **Durum:** Yazar onayı bekliyor
- **Eski site yolu:** `/hormonal-gecis/40-sonrasi/tiroid-menopoz-yorgunluk-uyku`
- **İşlem:** Makale canlı siteden kaldırıldı; kaynak dosya bu pakete taşındı.
- **Yayın kapısı:** Yazar `ONAYLIYORUM` demeden siteye geri alınmayacak.

## Dosyalar

- `makale-kaynak.astro`: Yayından kaldırılan kaynak makale.
- `kontrol-formu.html`: Yazara gönderilecek 5 dakikalık onay formu.
- `makale-onizleme.html`: Paket önizleme bağlantı sayfası.
- `metin-makale.pdf`: Önceden oluşturulmuş makale PDF arşivi.
- `metin-onay-formu.pdf`: Önceden oluşturulmuş onay formu PDF arşivi.
- `meta.json`: Paket durumu, deadline ve stil öğrenme kaydı.

## Stil Öğrenme
